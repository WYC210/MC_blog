# 北岸观景点 / North Lookout

- 位置：主路北端 `(0.5, -22.5)`，喷泉以北、两侧树林之间。木平台与地面齐平，不需要飞行或上楼。
- 沿主路走到平台中心，按 F 或点击“查看全岛”进入远景自由视角；地图上的观景点标记也可以点击导航。到达平台本身不会自动切换镜头。
- 镜头向北偏西后退并升高，让喷泉、摩天轮、工作台塔、IKUN 与海湾悬浮屋一起入镜。竖屏使用更远的机位。
- 拖动鼠标或单指滑动可绕岛旋转并调整俯仰；滚轮或双指捏合可缩放。普通点击、拖动、缩放和移动键都不会退出，角色停留在平台。
- 按 F / Esc 主动退出；手机也可点击“退出自由视角”。返回后恢复正常角色控制，不会自动重新进入。
- 开启系统“减少动态效果”时直接切换镜头。观景期间临时放远雾的起始距离，返回后恢复天气原本的雾效。
- 机位和平台范围位于 `world/layout.js` 的 `LOOKOUT`；造型及交互位于 `world/lookout.js`。复用现有相机接口，不修改引擎，也不新增实时灯。

保持本地预览服务运行后，执行 `npm run check:lookout`，检查步行到达、手动进入、构图、昼夜效果、鼠标/触屏旋转缩放、主动退出和横竖屏切换。截图输出至 `tools/.check/lookout-*.png`。

控制台快速到达：`__home.go('lookout')`。角色到达后按 F 进入自由视角。

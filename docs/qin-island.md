# 求仙岛：秦皇求仙入海处主题附属岛

## 位置与游览

- 主岛的 `LAND`、建筑和出生点保持不变；新岛位于主岛东侧。
- 新岛设计边界：`x = 84…236`，`z = -72…78`，圆角沙岸；西岸游客码头在 `(89, 18)` 附近。
- 两岛岸线之间约有 48 米开放水面，不建陆桥。从主岛东岸游泳，或驾驶原有快艇过海；快艇会在岸前停住，按 F 下船后游上岸。手机使用快艇按钮和摇杆。
- 返航时游回停船位置，再次登船。不要把快艇开上沙滩。
- 码头沿西侧道路向南到阙门，再沿中轴游览群雕、帝王像、求仙殿。两翼连接战国风情与求仙苑。
- 按 M 查看扩展地图；十四处站点使用引擎原有的 F/触屏提示和双语介绍卡，不占用原有 Dock 槽位。
- 扁鹊行医改为医者坐诊、病人仰卧伸腕、侍药者端盘的独立群像，增加脉枕、药柜、药臼与草药托盘。仰卧病人的眼睛位于朝上的面部，随头部朝向排列；浅青、陶土和米白色区分人物。原有位置保留，铺地替换原地表，不叠加共面地板；前方树木后移，三处烘焙补光改善夜间阅读，靠近正面铭牌可按 F 或触屏查看单语言双语卡。
- 始皇碣石行、屈原和徐福像的正面铭牌各有独立 F/触屏说明，区分碣石卢生记载、徐福求仙故事和屈原所属时代。史料依据为《史记·秦始皇本纪》与《史记·屈原贾生列传》，不将园区创作或后世传说当作考古结论。
- 影院十八个座位均可入座；按 F 或触屏坐下后进入视窗全屏观影，隐藏游戏界面。复用四幕影片的角色绘制与时间轴，按横竖屏重新构图，不裁切字幕，也不显示楼上缩略图。左上角切换语言，支持暂停、重播及 F/Esc/按钮退出；起身返回入座前的位置。减少动态时默认暂停，手动播放可继续；切换后台停止更新。不新增 WebGL 绘制、灯光或媒体下载。
- 庭院正前方的赵风综合体、左侧窃符救赵、右侧黄粱梦各有独立交互点。走近铭牌按 F，或在手机点击提示，即可阅读故事；使用卡片现有的中/EN 按钮切换，每次只显示一种语言。

## 实现说明

- `world/qin-island-layout.js`：边界、26 处景观、十个站点、随景点位置定义的七国旗位、阶梯与楼层高度。
- `world/qin-architecture.js`：共享的屋顶、阙门材料、石栏、人物、马匹、树木等方块构件。
- `world/qin-academy.js`：战国风情四柱三间牌楼、稷下学宫墙窗前廊、讲学与藏简陈设、局部烘焙灯笼。
- `world/qin-island.js`：地形、景区组装、文字图集、实体碰撞、局部屋顶隐藏、水车动画、烘焙照明和地图装饰。
- `world/layout.js`：仅扩展世界/导航边界，增加新岛陆地判断和高度；原主岛 `LAND`、泳池水面与原光照体积不变。
- `world/build.js`：挂接新地形、场景组、碰撞源、动态行为与着色器预热。
- `index.html`：十张中英文景区卡，复用 `.about` 底板和 `.about-text` 单语显示机制。
- `world/qin-guide.css`：仅限定景区卡片的阅读宽度、日夜底板、长标题换行和手机滚动，不修改引擎或其他卡片。

宫殿台基周围保留半米导航退让，避免路径平滑抄过三米高的台基角。入口阶梯和二层楼梯每级约 1/6 米，可正常步行上下。玩家进入殿内时隐藏局部屋顶，离开后恢复，不影响主岛建筑。

主殿后墙、东墙与西墙从台基 `y=3` 连续封闭至檐口 `y=11`，使用实体体素参与导航、飞行碰撞与灯光遮挡，窗格有不透明背板，不是空洞。西墙留出三米宽、三米高的回廊门，连接后方祈福轮平台；门厅与东侧楼梯保持畅通。

二层楼板覆盖 `x=141…181、z=-47…-35`，与三面外墙内侧衔接，楼梯北侧不再留空。实际楼板和导航高度共同读取 `QIN_GALLERY`，避免平台、楼板和可行走区域分别写死而出现错位；东侧下楼梯口保持开放。

正立面退到前廊柱后：廊柱位于 `z=-18`，木构浅色墙面位于 `z=-21…-20`，从 `y=3` 封到檐口。门额也封闭，不再从外部看到贯通的空腔。中央八米宽、四米高的门洞保持开放，两侧门扇向室内打开并有实体碰撞，前廊可横向通行。影院座椅向内移动，入口与东侧楼梯互不遮挡。进入室内才隐藏屋顶，站在前廊不会让外观消失。

上层檐廊设有楼板、木栏杆、立柱、承托、五组封闭窗格和顶梁，随屋顶组整体隐藏；这是参考照片的外观细化，不增设新的可进入楼层。匾额纹理位于木质背板之前，避免文字被背板遮住。

建筑使用 `BoxBatch` 合批；地形使用合并的体素面。所有文字匾额与七面旗的 14 个正反字面，共用一张运行时生成的 512×512 图集和一个网格，没有独立照片贴图。

七国旗不再保留旧版散落草地的坐标：齐旗在稷下学宫前侧，燕旗在壮士行旁，魏旗和赵旗分别位于新庭院入口左右，韩旗在韩非讲学堂前侧，楚旗靠近屈原像，秦旗移至秦风阙门前侧。旗位引用各展陈坐标并留出入口、铭牌与绕行通道。旗杆高 6.2 米，旗面由 1.3×1.7 米改为 1.9×3.4 米，底沿距地 2.35 米；底座和旗杆有实体碰撞。国名使用独立的 32×32 方形字区，正反面各自朝外显示，避免横匾贴图挤压、背面镜像与木背板穿插。旗帜只是本项目的主题标识，不代表考证复原的战国实物军旗。

新岛使用 `78×15×77` 的独立光照体积（约 352 KiB 显存数据），不扩大或降低原岛 `86×30×90` 光照体积的采样精度，也不新增实时灯。新岛材料在着色器预热期间绑定自己的体积，保留引擎原有材质钩子，避免重复注入光照代码。

“始皇碣石行”群雕使用独立的浅陶土人物、暖灰马匹、古铜车辇和灰青车盖配色；面部、手部、冠帽及马鞍有明度差，不再用深色染色叠加灰石底纹。仅群雕传入专用配色，不改变其他建筑、雕像或祈福轮的材料。雕塑本身不自发光，不调整全岛曝光。

群雕基座两侧各设五盏矮脚投光灯，写入新岛已有烘焙光照体积，覆盖前后两排和两端。灯具沿用现有合批，仅增加 240 个三角形，不新增绘制批次、贴图或实时灯光，保留 32 人、20 马、2 车的完整阵列。

“壮士行”、战国园三组浮雕及“胡服骑射”使用浅陶土衣袍、浅色面部与深色冠帽/腰带，并有小尺寸眼部细节。赵风综合体、窃符救赵、黄粱梦的十五个人物统一前移 0.2 米，配灰青色分格衬底，以实体纵深和色差区分人物与背景墙。上述展陈另外使用十一盏合批矮脚灯提供烘焙补光，不增加实时灯或全局曝光。

骑射像前方原位于 `(128, -15)` 的松树连同树干碰撞移至侧后方 `(133, -27)`，保留树木数量与园林层次，腾出骑手、马头、弓及铭牌的正面和斜侧观赏视线。

本次功能没有修改 `engine/`，没有更新 `engine/manifest.json`。仓库自检报告的已有引擎差异保持原样。

## 夺玺与统军互动

秦始皇 NPC 在雕像周围巡行，靠近后主动招呼。第一次按 F（手机点击提示）夺取玉玺，触发锁定镜头、军士苏醒和围圈护驾；事件名称、字幕、提示及状态使用同一套中英语言切换。NPC 手持浅玉色印身和金色印钮，与夺玺文案对应。

夺玺后退开再靠近可选择“取代秦始皇”。玩家沿用原模型，替换为本地生成的 64×64 黑金帝王皮肤；原 NPC 隐藏，军士从当前位置改列八列四排方队，统一朝向玩家，整队展示后恢复操作。首次夺玺的防御圆阵与取代后的检阅方队独立规划；以后从介绍卡唤醒军队也使用方队，不重复围圈演出。该互动属于虚构玩法，不作为历史事件介绍。

军士在室外编队随行；玩家进入求仙殿、稷下学宫或韩非讲学堂时，在门外列阵并留出入口，出门后继续跟随。飞行、游泳、乘艇或离开附属岛时，军士原地等待 25 秒，及时落地回岛可继续随行；超时后自行走回原位并逐渐石化。取代进度与皮肤在本页会话内保留，回到碣石行按 F 打开介绍，可再次选择“唤醒军队”；刷新页面会重置这段玩法。

`world/qin-emperor-encounter.js` 管理事件、镜头与原生介绍卡入口；`world/qin-encounter-actors.js` 更新既有雕像实例，不额外复制军士模型；`world/qin-army-follow.js` 使用预分配路径数组与独立的室外导航网格。网格边缘逐段检查通行性，避免端点可站立但中间有窄障碍时卡住；此导航不修改玩家的建筑通行规则。跟随阶段不增加围堵玩家的动态碰撞，也不新增实时灯。

持矛军士的右手握点与矛杆对齐，武器通过持握手的最终变换驱动，而不是单独摆动。专项检查对 24 名持矛军士采样 576 组石化/苏醒、步态、转向及抬手姿态，确认握点始终位于矛杆上；恢复雕像时同步恢复原位姿态。

`world/qin-cinematic-occlusion.js` 为剧情镜头提供临时遮挡透视：视线被秦始皇大雕像遮挡时，只淡化该雕像与台基，镜头进入雕像内部时完全透过，不改变军士或周边建筑。效果使用原实例的遮罩和像素渐隐，不新增绘制批次、实时灯或后处理；镜头移开后恢复，结束、跳过或重置剧情时立即关闭。

`npm run check:qin-encounter` 覆盖桌面与手机的夺玺、取代、方队朝向、换肤、三个建筑门口警戒、飞行等待及恢复、离岛超时归位、介绍卡再次唤醒、F/触屏及中英切换，并保存日夜截图。此次演出视角实测桌面最多 31 draw calls / 188800 三角形，手机最多 19 draw calls / 150724 三角形；通用启动检查另为桌面 58 draw calls / 约 19.7 万三角形。

## 手机旅行社

打开游戏内手机（桌面按 P，触屏点击底部手机图标），进入“旅行社”，点击景点即可立即传送，不使用地图的自动步行或飞行导航。原有 GitHub、余烬行囊和 echoes 应用保留。

- 覆盖全部 26 处景观，另有求仙岛码头和求仙苑入口，共 28 个游览落点；底部固定提供“返回主岛”。
- 按秦皇游线、战国风情、海滨园林筛选，也可输入中文或英文景点名称搜索。界面随已有中/EN 开关切换，一次只显示一种语言；已有景点沿用地图专属图案。
- 落点位于观赏区或通道，而非雕像中心、座椅、井口或水中。求仙殿与影院落在三米层，全景馆落在七米层，升仙台使用实际台面高度；附近落点受阻或楼层不符时拒绝传送并提示。
- 传送会取消原有导航、钓鱼、飞行、游泳、乘艇和休息状态；快艇停留在原地。镜头立刻回到玩家并面向景点，自动收起手机，显示到达提示。
- 夺玺/取代演出、沉浸观影和锁定观景期间不允许传送。不会清除玉玺、换肤或统军进度；同岛传送后军队仍步行追随，进入室内依旧门外警戒，返回主岛后按原有 25 秒等待规则归位。
- `world/travel-destinations.js` 集中维护安全落点，`world/travel-agency.js` 扩展原生手机卡片，`world/travel-agency.css` 提供可滚动触屏列表；不修改引擎、不添加 WebGL 模型、灯光或逐帧 UI 更新。

## 主殿挡雨与飞行楼层

`world/qin-palace-structure.js` 从实际楼板、楼梯和屋顶的 BoxBatch 变换建立结构边界，统一提供场地 `levels` 与 `collides`。二楼楼面登记为 7 米、板底为 6.75 米；飞行从下方上升或从侧面接近会被楼板挡住，在楼上取消飞行或主动下降可落回二楼，不再误认一楼为唯一落脚面。楼梯碰撞沿用引擎允许跨台阶的高度容差，以免阻塞普通步行。

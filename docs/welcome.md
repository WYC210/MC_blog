# 世界欢迎页

首次打开网站时，镜头停留在原有开场的高空位置，背景世界继续渲染。按任意普通按键、点击空白处或点击“进入世界”后，欢迎信息淡出，镜头下降到角色身后。首次输入不会同时触发移动、跳跃或快捷菜单。开启系统“减少动态效果”时，仍显示欢迎页，但确认后直接进入角色视角。

- 站点名称、标语和 logo 自动读取 `homecraft.json`，读取失败时使用 `index.html` 中的备用文案。
- 简介、提示语在 `index.html` 的 `#welcome` 中编辑，支持现有中英文切换机制；布局在 `world/welcome.css`。
- 普通模式不自动下载高清材质。欢迎页的“高清材质包（可选）”沿用引擎现有的画质确认框，确认会刷新页面并启用 Ultra。手机推荐普通模式。
- 已启用 Ultra 时，先完成普通材质的场景预热并显示欢迎页，再在后台下载高清材质。加载期间可以直接进入；下载失败则保留普通材质并显示提示。Ultra 本身的渲染能力检测与失败回退保持不变。
- 通过传送门抵达或浏览器前进、后退返回时，沿用原有抵达流程，不再拦截欢迎页。其他未添加 `#welcome` 的世界保留原有自动开场。
- Tab 用于选择欢迎页按钮；系统快捷键、修饰键和鼠标滚轮不会意外进入。

验证：先启动 `python tools/serve.py`，再运行 `node tools/check-welcome.mjs`、`npm run check:input` 和 `npm run check`。欢迎页截图保存在 `tools/.check/computer-welcome.png` 和 `tools/.check/phone-welcome.png`。发布前请用真实手机检查触控和流畅度。

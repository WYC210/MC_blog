# 秦皇岛长城：第一批资料参考模型

实施日期：2026-11-08。依据第一阶段研究的 10 个 A 级展项实现代表性局部低多边形模型。A 级不是“完整复原已被证实”，本批也不是摄影测量、实景扫描、DEM 地形或完整遗址模型。

## 三种可信程度

1. **文本或照片明确约束的特征**：例如九门口河中桥墩与水门数量、拿子峪黄色条石及小型旱门、板厂峪柱状崖壁。通过构件而非单纯改色表达。
2. **按资料约束的比例**：镇东楼城台采用 44×30.4×11.75 米、门洞宽 5.8 米/高 7.5 米、上部楼体宽 20 米/深 10.1 米/含屋顶高 13.7 米，统一乘 0.075；屋顶与楼身的内部高度分配、出檐、窗数量位置仍是简化，不当作测绘尺寸。数字来自单一景区资料，尚待交叉核验。
3. **展陈估计与编排**：全部山形、路线转折、敌楼位置、村落排列、缺损位置与各构件间距都不是实测。界岭口两台并置作构件对照，不能解释为真实平面。为了适配长桌延长的背景墙段不代表已核实的历史长度。

## 时间版本与待补证项

- 界岭口采用 2025 年修缮报道所示的局部特征，不把施工照片当作 2026 年最新外观。
- 刘家口采用发表于 2022 年文章中标注的残楼图；拍摄时间和页面换图时间未核实，不称为 2023 年修缮后或 2026 年现状。
- 其他照片的来源发布日期不自动等于拍摄日期，统一保留第一阶段研究的限制。
- 北翼、三道关、义院口、重峪口、桃林口、罗汉洞仍为 B 级；南翼、花厂峪/花场峪、冷口、城子岭口仍为 C 级。本批不编造新的替代模型，原艺术示意保留并在列表、卡片和桌面标题标注“待补证”。
- “城子峪”和“城子岭口”保持独立；九门口继续标注辽宁周边关联。原地图不改成真实地理路线。

## 实现与回归

- `world/qin-great-wall-reference-models.js` 使用显式高程折线构图、阶梯墙、空心敌楼、分块拱券和特色构件，复用原来的一个实例批次与地形/线框缓冲。拱门是几何开口，不是贴黑色矩形。
- 参考模型按 `min(width / 31.2, depth / 3.6)` 整体缩放；建筑不因长桌而仅沿一个轴拉长。最高构件必须低于二楼楼板，实例不得超过 1024。
- 材质仍为原生小纹理与实例颜色；条石使用低饱和石黄色，未新增金属贴图、实时灯或后处理。仅切换时生成 CPU 构件，逐帧循环不新增对象。
- 保持桌位、碰撞、房间进入后自动轮播、离开/上楼暂停、手动暂停、减少动态及后台暂停行为。
- `node tools/check-qin-great-wall-models.mjs` 检查 A 级覆盖、来源、模型边界、尺寸比例、九门口数量及真正开口、残楼不补顶等。
- `npm run check:qin-great-wall` 检查 20 项几何差异、缓冲复用、交互、双语提示、步行、轮播；对 10 个参考模型分别保存桌面与手机截图并检查渲染预算。
- `npm run check` 为项目整体回归。软件渲染的帧耗时不能代表实际手机性能；发布前需真机确认。

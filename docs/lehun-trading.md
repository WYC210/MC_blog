# 乐魂交易研究室

乐魂二楼在 y = 19 的原有楼板上改为交易研究室，一楼健身房与东侧楼梯保留。

- 北侧：六屏交易工作台、人体工学椅、键鼠、主机、笔记本和杯子。
- 西侧：K 线复盘黑板、图表板报、矮文件柜；南侧为讨论长椅、茶几和植物。
- 东侧：保留楼梯口和通行走廊，增加护栏。家具碰撞使用实际楼层高度，不影响楼下通行。
- 装饰材质以浅木、深灰金属和低饱和绿色为主，地毯划分工作区与复盘区。

`world/lehun-trading-art.js` 程序绘制 K 线、均线、成交量、分时、盘口、自选列表和板块热图。所有数值都是固定的场景示意，不连接真实股票接口。六块屏幕、两块板报和顶部行情条共用一张 1024×1024 图集、一个网格、一个绘制调用；没有逐帧重绘或网络行情请求。

`world/lehun-trading.js` 构建家具、装饰、灯具与显示面。`world/lehun-furnish.js` 保留楼板、楼梯、一楼家具，并装配研究室。

## 开发者来访事件

玩家走进乐魂一楼、楼梯或二楼时，开发者 NPC 会立即来到二楼北侧研究桌的椅子上，朝向六屏行情，做看盘和整理思路的小动作。附近可以听到间歇性的复盘自语；楼下和水面下不会显示二楼对白，也不会因为飞过屋顶误触发。

事件期间优先保持研究状态，不会在入夜时突然离开。玩家离开区域两秒后恢复原先日常活动；刷新仍保留事件前的有效日常存档。区域与对白配置在 `world/resident-events.js`，双端检查使用 `npm run check:resident-events`。所有行情和自语仅为场景表现。

## 照明

原 `LIGHT_VOLUME` 的南边界只有 z = 34，没有覆盖 z = 36–50 的乐魂。现在 `world/layout.js` 将南边界扩展到 z = 54，烘焙纹理为 68×30×70，约 558 KiB 显存数据。二楼的主灯、板报洗墙灯、桌面灯、楼梯口灯和长椅灯全部写入 `bakes`，不增加实时光源或动态阴影。

## 验证

先启动 `python tools/serve.py`，再运行 `npm run check:lehun`。检查包含上下楼与走廊通行、家具碰撞、光照覆盖、图集合批、桌面和手机昼夜截图，以及绘制预算。截图位于 `tools/.check/lehun-trading-*.png`。最后运行 `npm run check` 做全站回归；发布前仍需用真实手机确认操作和帧率。

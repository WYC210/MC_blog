# IKUN 居民与配置核对

当前实现已迁移为工作台房屋中的站长住户，见文末“站长入住工作台”；以下保留最初设计记录。

- 复用示例的 `terry-skin.png` 和引擎人物模型，保持玩家皮肤、跨站访客皮肤不变。
- 在 IKUN 四米高的房间内布置床，显式沿楼梯进出，陆地使用现有寻路，水上活动使用避障水路。
- 白天轮换散步、海滩坐卧、钓鱼、摩托艇活动，夜晚中断活动、下艇、游回岸边并步行回家睡觉。
- 座位和摩托艇有占用检查，不抢玩家正在使用的资源；距离接近且无遮挡时招手，设置离开距离和冷却时间。
- 名牌使用 DOM，钓竿合并绘制，床复用已有家具批次，不加实时灯光。
- 修复邮箱、联系方式和双语介绍的填写位置；以 `homecraft.json` 的站名为准，保留尚未提供的 Logo、玩家皮肤和天气城市待确认。
- 遵守用户暂不运行测试的要求，只同步回归用例，后续可运行 `npm run check:resident` 和 `npm run check`。

## 2026-11-10：驾驶修复与刷新恢复

- 修正 NPC 转向输入与摩托艇实际转向相反的问题；巡航上限为 6 m/s，不使用加速，转弯、靠岸前减速。船体前探受阻时先刹车，停滞后探测安全退路、倒退脱困并重新寻路，最多尝试三次；无法完成则结束活动并冷却，而不是无限顶墙。
- 水路用船体尺寸而非游泳点校验，使用粗网格 A*、细网格回退和路径简化；取消固定 30 秒强制下艇。玩家驾驶控制及 `engine/` 不做修改。
- 默认启用居民本地存档，保存坐标、高度、朝向、活动、剩余等待时间及行程意图。陆地行程恢复时重新寻路；房屋楼梯按明确阶段和路段恢复；驾驶恢复船位但不恢复速度，重新检查船体、占用和返航路线。当前昼夜作息优先于旧存档。
- 每 3 秒活动时间保存一次，页面隐藏和 `pagehide` 时补存。没有有效存档、数据损坏、版本不兼容、位置不安全或存储被禁用时，安全使用原来的初始化流程；存储异常不影响 NPC 活动。
- 存档是当前浏览器 `localStorage`，按站点目录隔离；不同域名、协议、端口、浏览器或设备不共享。关闭页面期间不模拟活动，也不是所有访客共享的服务端世界。更换预览服务器端口会使用另一份存档。可在 `home.config.js` 的 `resident` 中设置 `persistent: false` 关闭保存及恢复。
- `npm run check:resident` 覆盖存储校验以及桌面、手机视口的实际刷新恢复；`npm run check:resident-boat` 覆盖驾驶输入、岸线、边界脱困、预约和夜间退出；`npm run check:jet-ski` 检查原有玩家控制。
- 本机验证：NPC 原先撞边界的路线可以返航，7 条岸线/边界路线均到达，未穿入障碍或瞬移船体。桌面和手机视口实景截图已检查；这些是本机软件渲染与模拟时间结果，不代表真实手机帧率，上线前仍需实机检查。
- 已知性能边界：最远东侧返航仍使用同步寻路，本机测试约 0.7 秒总规划时间，可能造成单次卡顿；常见短路线远低于此。后续若频繁安排跨岛驾驶，应将规划分帧或移入 Worker，不应把该测试当作寻路已满足每帧预算。
- 全站 `npm run check` 的本地启动、卡片检查可执行，但外部世界目录请求因 DNS 解析失败导致命令退出失败；夜间音乐距离衰减测试也失败，已用未修改的居民模块复测，结果相同。保留这些独立问题，不改动音乐或网络配置。

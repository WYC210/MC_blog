# 水面反射与性能

桌面 Ultra 使用镜像相机生成水面反射，每隔一帧刷新。手机不启用场景平面反射。

## 距离与范围

- 水面进入主相机视野、天气晴朗、相机位于水面上方时，才启用反射。
- 相机到主岛或秦岛边界的最近水平距离需要不超过 80 米。这不是反射物体的距离上限。
- 反射相机跟随主相机远裁剪距离，主相机距离随天气与雾效调整。
- 按当前水面范围与主相机视锥的交集收紧反射物体剔除范围，保留波纹扰动余量。

## 反射专用简化

- 秦岛在距岸 32 米以外可使用远景细节；已有建筑低模只有在反射贴图上的预计误差小于 2.5 像素时才启用。近岸保留原始几何。
- 主画面、角色实例顺序、碰撞和阴影不变；反射完成或抛错时恢复原来的可见性和实例数。
- 方块实例与体素表面使用反射专用副本。体素按空间分组，仍以原批次一次提交，不为每组增加 draw call。
- 将包围盒投影回水面；只有倒影的整个保守落点范围都被不透明地面覆盖，才省略该实例或表面分组。海湾、池塘、网格外海面、接近地平线的不确定情况保留。
- 波高和纹理扰动留有余量；后方高建筑只要能在岸前水面形成倒影就保留，不按离岸距离直接删除。
- 阴影需要重绘时不执行反射简化，避免影响静态太阳阴影。
- 反射副本不重复计入高清材质使用次数，不额外提升稀有材质层。

这不是完整的建筑遮挡剔除：被墙体遮住的几何仍可能提交。主岛复杂模型与动态细节也仍有反射成本。减少三角形不等同于同比提高帧率，需结合真实设备 GPU 与 CPU 时间判断。

## 斜裁剪相机的落点计算

反射相机会把近裁剪面弯到水面。此时反投影固定深度得到的齐次点 `H` 可能满足 `H.w < 0`，也可能落在无穷远；直接使用 `H.xyz / H.w - camera.position` 会把射线翻到相机后方，使陆地覆盖测试误入“无法确定，保留几何”的分支。

落点计算使用齐次方向 `H.xyz - camera.position * H.w`，不除以 `H.w`。这样深度裁剪不会改变射线的朝向，`H.w = 0` 也能正常求交。真正跨越地平线、位于相机后方或投影不确定的包围盒仍保留。

没有缩小现有的 NDC 0.05 投影余量和水位上下 0.3 米波高余量，也没有按离岸距离隐藏雕像。低机位下，倒影范围和余量可能覆盖大片海面，因此这一修复不保证所有机位都大幅减少提交量。

### 2026-11-17 修复对照

本机 RTX 2060 / Chrome ANGLE D3D11，1600×1000、DPR 1；只替换落点算法进行同机位对照，其他距离简化和缓存保持相同。秦岛主要建筑/雕像批次的反射提交实例数如下：

| 相机位置，均朝向 `(160, 7, 10)` | 修复前 | 修复后 |
| --- | ---: | ---: |
| 主岛远眺 `(0, 12, 35)` | 3,805 | 2,429 |
| 主岛岸边低机位 `(34, 2.5, 18)` | 4,629 | 4,629 |
| 主岛岸边高机位 `(34, 12, 18)` | 4,629 | 1,181 |

高机位的反射总提交约从 116,800 降到 73,000 三角形，draw calls 从 19 降到 18；低机位保留正常的雕像倒影。这些是提交量变化，不是整帧帧率增幅，更不是 RTX 3050 性能保证。主画面和后处理未修改，部分视角的整帧三角形仍超出 200,000 预算。

## 验证

运行 `npm run check:reflections`，默认读取 `tools/.serve-url` 的预览地址。覆盖桌面/手机、主岛望向秦岛、秦岛近岸和东岸、离屏、隐藏、相机层、天气、水下、缩放以及抛错后的恢复。

单测包含实际斜裁剪矩阵、负齐次坐标、无穷远射线，以及不同相机高度、FOV 和镜像朝上的组合。浏览器回归在高位岸边比较开启/关闭陆地过滤的提交量，并冻结动画时钟比较主画面 HDR 目标：前景海面不允许超过 `1/255` 的颜色变化；全景仅允许不超过 0.01% 的孤立陆地接缝像素差异，单通道最大差异低于 0.12。出现差异时同时输出对照图，避免把地面接缝露出的亚像素水面误判为倒影轮廓丢失。

默认浏览器检查使用 SwiftShader。设 `REFLECTION_GPU=hardware` 可使用浏览器默认 GPU 交叉验证，但该脚本只验证图像与提交量，不报告真机帧率。

输出在 `tools/.check/reflections/`。报告分开记录反射、主画面、水面深度和后处理的 calls/tris，并通过临时禁用反射细节模块进行同机位对照；SwiftShader 时间不能代表真机帧率。常用视角预算仍为 60 calls / 200,000 tris，超标需继续评估，而非仅依据平均帧掩盖反射刷新帧峰值。

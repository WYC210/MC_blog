# 夜晚星空

晴朗夜晚显示蓝紫色银河、尘埃暗带和三层不同大小的星点。星空缓慢转动，星点轻微闪烁；原有的偶发流星雨继续由 `world/night-nature.js` 管理。

## 预览

运行 `python tools/serve.py`，在页面的天气菜单中选择晴天和夜晚。也可以在浏览器控制台运行：

```js
__home.setTimeMode('night');
__home.setWeatherMode('clear');
__home.rig.showcase([-50, 7, 64], [0, 30, -4]);
```

调用 `__home.rig.skipIntro()` 返回正常视角。照片式星轨和密集流星雨没有作为常驻效果加入。

## 实现与约束

- `engine/world/stage.js` 的天空着色器负责银河、星点及天气遮挡。这是本次有意保留的引擎定制，升级引擎时需要合并。
- `world/night-lighting.js` 设置本岛夜空和远景雾的蓝色调，原有地面灯光、曝光和环境光强度不变。
- 只复用天空现有的单次绘制，不添加网格、实时灯、阴影或后处理。
- 噪声纹理在启动时生成，大小为 128×128 RGBA（64 KiB GPU 数据），不下载天空图片。每帧只更新两个数值，不创建对象。
- 银河和星点随昼夜淡入淡出，并受云层、雨雪天气和浓雾遮挡。白天、全阴和后台页面暂停星空动画；系统启用“减少动态效果”时，保留静态银河并停止转动与闪烁。
- 天空与远景雾的衔接跟随相机高度、视线方向和雾的远端距离，不再把水平视线以下全部填成纯色。高空可见的远景之外延续天空，实际海面仍由海水材质绘制。

## 自检

启动预览后运行 `npm run check:night-sky`。检查桌面和手机视口的启动、渲染预算、银河像素输出、天气遮挡、昼夜切换、减少动态效果，以及 20、60、120 米视角的天空衔接。截图保存到 `tools/.check/night-sky-*.png`。

另运行 `npm run check` 和 `npm run check:night-lighting` 检查站点及原有地面照明。自动化使用软件渲染，帧耗时不能替代真实手机体验；发布前仍需手机实测。

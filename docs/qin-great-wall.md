# 秦皇岛长城投影桌

建模资料调查及证据缺口见 [实景资料调查（2026-11-08）](qin-great-wall-research.md)。10 个 A 级展项已应用到代表性局部参考模型；其余 10 项保留原艺术示意并标注“待补证”。全部模型均非测绘复原，具体依据及简化范围见 [参考模型实现说明](qin-great-wall-modeling.md)。

## 位置与交互

- 求仙殿一楼后墙前、二楼楼板下方，中心坐标 `(160.5, 3, -44)`，桌面尺寸 `32 × 4.6 m`，桌面高约 `0.78 m`。后沿距墙 `0.7 m`，两端留出约 `3 m` 通道，前方保留观展空间。
- 从殿门进入后直走到后排，南侧交互位置为 `(160.5, -40.2)`。按 `F` 或点击手机互动提示打开引擎原生卡片；求仙殿介绍卡也提供入口。
- 桌面为木材、深色金属与铜色边框，青蓝地形网格、微缩长城、敌楼、扫描线及金色选中环组成投影。影院、中央通道、东侧楼梯及二楼航船沙盘保持原位。
- 卡片支持名称/区域搜索、分区筛选、编号地图点选、上一处/下一处、自动巡展和中英切换。选中城段替换整座桌面虚影的地形、墙体、敌楼与特色构件，不只是改标题和标记。点“查看桌面虚影”收起卡片查看三维效果。
- 角山显示陡阶与裸岩；老龙头显示海岸城台、入海石城及楼阁；山海关突出镇东楼；董家口显示空心敌楼与村落背景；板厂峪显示柱状崖壁；拿子峪显示黄色条石带与小型旱门；城子峪、刘家口保留残缺；界岭口突出扇形墩台；九门口显示 8 个河中桥墩与 9 个真实拱券开口。
- 每处介绍附可打开的资料来源；搜索及筛选在语言切换和重新打开时保留。
- 进入求仙殿一楼房间即自动巡展，每 `7` 秒更换一处，无需打开卡片。离开房间或上二楼时暂停，重新进入一楼恢复自动巡展，并重新计时。房间判定使用玩家位置和高度，不使用镜头位置。
- 手动选段、上一处/下一处或暂停按钮可暂停当前参观期间的轮播；自动巡展按钮可恢复。收起卡片不停止轮播。后台、离屏、观影和系统“减少动态”期间不推进动画或轮播，恢复后继续。

## 展示口径

资料核对日期：2026-11-08。当前收录 19 处秦皇岛市域相关城段、关隘与翼城，另列 1 处周边关联点九门口；并不宣称是完整文物普查名录。

包括老龙头、南翼长城、山海关、北翼长城、角山、三道关、义院口、董家口、板厂峪、拿子峪、花场峪、城子峪、界岭口、重峪口、刘家口、桃林口、冷口、城子岭口、罗汉洞，以及单列的九门口。

“明代长城”表示时代与防御体系，不能当作与“角山长城”并列的一个独立景点。翼城、关口和城段也可能同属一套防御体系，不代表相互独立的长城。

九门口明确标注辽宁省绥中县、非秦皇岛市域；冷口按青龙与迁安边界关联展示。地图坐标与连线仍为艺术示意，未使用真实经纬度或测绘墙线。10 个参考模型依据照片约束构件形态，镇东楼采用景区公布的尺寸约束比例；地形、构件距离和不可见细节仍作展陈简化，不是遗址精确复原，不可用于户外导航。收录不表示对外开放，不提供未开放长城穿越线路。

来源集中在 `world/qin-great-wall-data.js` 的 `WALL_SOURCES`：秦皇岛市政府公开文章、政府转载的地方报道，以及辽宁省文化和旅游厅《九门口长城》。其中市域明长城 `223.1 km` 的口径来自秦皇岛市政府《秦皇岛因长城而更加雄奇》（文章 ID `630044`）。各条数据通过 `sources` 显式关联，避免只列一个笼统网站。

## 代码与验证

- `world/qin-island-layout.js`：投影桌尺寸、位置与 `qin-great-wall` 站点。
- `world/qin-great-wall-data.js`：点段、示意位置、分组、来源、搜索。
- `world/qin-great-wall.js`：桌体、投影、碰撞、烘焙灯光和可见性更新。
- `world/qin-palace-floor.js`：二楼下方的一楼通行面、避障路径和点击定位；`engine/world/ground.js` / `player.js` 支持场地路径及显式楼层定位，避免进入后排展区时误上二楼。
- `world/qin-great-wall-models.js`：20 个展项的模型切换，共用可复用几何缓冲和一个实例批次。
- `world/qin-great-wall-reference-models.js`：10 个参考模型，阶梯墙、空心敌楼、拱券、山崖与城台构件；按统一比例适配桌面。
- `world/qin-great-wall-evidence.js`：逐项说明依据、估计与省略范围，提供可打开的具体建模来源。
- `world/qin-great-wall-guide.js` / `.css`：原生卡片内的双语浏览界面。
- `tools/check-qin-great-wall-models.mjs`：无浏览器几何检查，覆盖 A 级范围、来源对应、真实拱洞、尺寸比例、实例数量及桌面/楼板边界。
- `tools/check-qin-great-wall.mjs`：桌面/触屏交互、数据完整性、步行碰撞、动画暂停、双语、参考状态、全部参考模型截图与渲染预算回归。

运行 `npm run check:qin-great-wall`、`npm run check:qin-palace-media` 和 `npm run check`。默认读取当前预览服务器的 `tools/.serve-url`；也可在单项脚本后传入地址。输出存入 `tools/.check/`，其中 `qin-great-wall-report.json` 记录实测预算。

桌体并入已有 `BoxBatch`，分段模型使用一个最多 1024 实例的可复用批次，没有新增实时灯或阴影灯。参考模型在 31.2×3.6 米构图范围内配置代表性墙段，再整体等比缩放，不按桌宽单独拉伸建筑。切换不会不断创建 GPU 几何体、材质或纹理；测试对每个点段的实际地形和实例矩阵计算指纹，确认模型确实不同。投影超过 60 m 隐藏，离屏、后台、观影或减少动态时暂停动画。三维主循环不创建几何体、材质或临时向量；模型、资料卡与文字纹理只在交互或巡展切换时更新。软件渲染帧耗时不等同真机体验，发布前仍需在实际手机检查。
